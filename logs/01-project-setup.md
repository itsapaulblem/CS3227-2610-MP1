# 01 – Project setup

## What was requested

The project was started as a personal workout-logging utility named FitLog. The
initial request was to establish a clean Java project structure and supporting
repository files before feature work began.

## What landed

- Initial source and documentation directories, `.gitignore`, and a root README
  were created.
- The initial scaffold was committed as `686941b` (`Initial project scaffold:
  directory structure, .gitignore, README`).

## Notes

Later work adopted Java 25, Gradle, JavaFX, JUnit, and the `fitlog` package. The
initial scaffold did not yet include those tools or the final architecture.
